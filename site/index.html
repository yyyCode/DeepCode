循环、上下文、记忆、提示

四块都是从零写的，每一块都有可复现的 benchmark 或测试顶着。 估出来的数，文档里就写着是估的。

你的话 → 模型：一次决策 → 调用工具

↺ 结果写回消息，再问一次 —— 直到它 end_turn 把话交回你

src/core/loop.ts

一次请求，一次决策

模型每被叫一次，只做一件事：点名工具，或者把话交回给你。没有 ReAct 的 Thought 步，也不为「想一想」多跑一轮。 同一批调用里，Read / Glob / Grep 并发跑、默认不问； Write / Edit / Bash 串行，每一条都先停下来问你。计划模式不新增循环 —— EnterPlanMode / ExitPlanMode 是两个普通工具，进入后写工具从清单里消失， tool.check 兜底拒绝。

N 次工具 = N+1 次请求，额外请求 0（benchmark 钉住）

src/core/context-shaping.ts

五道闸，由轻到重

重了先外置大工具结果，再砍最老的整轮，再清可重新获取的旧结果，只在更老的一段上做摘要，最后才全量摘要。 第 2–4 层是读时投影：转录一个字不动，--resume 接回来仍是全文。

> 50 000 字符的结果落盘，消息里留 2 000 字符预览

src/core/memory.ts

一条记忆，一个文件

记忆落成项目目录里的 Markdown，MEMORY.md 只是索引，每轮随系统提示进去；正文只在被召回时注入，最多 5 条。 默认关键词匹配，零 API、可离线复现；配 memory.recallModel 才让模型挑。

项目级，不是用户级 —— 换个目录就是另一份记忆

src/cli/prompt-text.ts

静态前缀，动态尾巴

角色、安全、工作方式、工具、输出这几节不随项目变，拼成静态前缀；环境、指令文件、记忆、计划提示走动态尾巴。 Anthropic 端点只在静态段末尾打一个缓存断点，换项目、换日期都打不散它。

静态正文约 310 token；pnpm bench:prompt 可复现 20 轮缓存账

还有 --resume 接上一次会话 插件与内建同一条链 Anthropic / OpenAI 兼容端点，只改三样配置

每一块的取舍、偏差与 benchmark 都在 技术文档 里； 做不到什么、哪些数是猜的，见 已知限制。

工具调用必经三道闸

按顺序过，任何一条 allow 规则都绕不过去。

  1. tool.check

    先预览，再停下

    把要跑的命令、要动的文件摆给你看，然后在终端上等你一个答案：y 这一次， a 本次会话这一类（Bash 按那一条命令记，其余工具按整个工具记），别的输入都算拒绝。

  2. sandbox

    路径闸

    只对 Bash 生效的一道可选闸，按命令行里的路径判要不要放行。

  3. 真进程 / 真文件

    到这一步才动手

    前面两道都过了，才真的去改文件、起进程。

三条兜底 非 TTY 默认拒绝 链尾无人应答 = deny 不认识的工具 = deny

现在就试

需要 Node ≥ 20 与 pnpm。不带参数就是交互式 REPL。

安装 git clone https://github.com/yyyCode/DeepCode && cd DeepCode && pnpm install && npm link
配 key mkdir -p ~/.deepcode && cat > ~/.deepcode/config.json <<'EOF' { "apiKey": "sk-ant-..." } EOF
开工 cd /你的项目 && deepcode

key 也可以放环境变量（ANTHROPIC_API_KEY），或者换成任何 Anthropic / OpenAI 兼容的端点 —— 细节见 技术文档。
